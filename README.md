# 4 Channel Mixer for Eurorack

> **This repository is archived.** The 4 channel mixer files are now in the [7 Channel Mixer](https://github.com/lonesoulsurfer/7_Channel_Mixer) repository, with the build guide and the video. Use that repository for new builds. The files here stay available, but they will not change.

This is a small 4 channel audio mixer for modular synths. It fits in any Eurorack case.

## Build guide and video

- Step-by-step build guide on Instructables: [7 Channel Mixer (+ a 4 Channel Option)](https://www.instructables.com/7-Channel-Mixer-a-4-Channel-Option/)
- Video on YouTube: [7 Channel Mixer](https://youtu.be/h-TxdCl6BcE)

## Build it

1. Download this repository. Click **Code → Download ZIP**, then extract the ZIP file.
2. Send `Gerber Files - PCB.zip` and `Gerber Files - Front Panel.zip` to a PCB maker.
3. Get the parts in the [parts list](Parts%20List.pdf).
4. Solder the parts and attach the front panel.
